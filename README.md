# ai-influencer-kitInfluencer AI is a Python-based automation platform that generates monetization-ready social media content and videos using AI, APIs, and media processing tools.

The system automatically:

Fetches motivational quotes from online APIs

Downloads high-quality background images from free stock platforms (Pexels API)

Generates 90-second vertical (9:16) Facebook-ready videos

Applies styled text overlays with dynamic layout

Adds optional background music

Exports production-ready MP4 files

Supports automated scheduling (e.g., 9 AM Monday–Friday via Task Scheduler)

Built using:

🐍 Python

🎥 MoviePy (video rendering)

🖼 Pillow (image processing)

🌐 REST APIs (Pexels, Quotable)

⚙️ Streamlit (interactive UI)

🗓 Windows Task Scheduler (automation)

🚀 Key Features

Automated daily video generation

Monetization-length (90s) vertical Facebook videos

API-based content sourcing

Fallback systems (offline quote support)

Branding-ready architecture

Modular project structure

Local-first deployment (no cloud dependency required)

🎯 Purpose

The goal of Influencer AI is to create a scalable content production engine that enables creators to automate high-frequency posting, improve consistency, and maximize monetization opportunities on platforms such as Facebook.

It transforms AI, APIs, and automation into a repeatable content pipeline.
